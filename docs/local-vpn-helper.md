# Локальное управление VPN-клиентами

Дополнительная служба запускает установленные операции AntiZapret для создания и удаления клиентов OpenVPN и WireGuard. Операция WireGuard создаёт варианты WireGuard и AmneziaWG 1.5 одним вызовом `client.sh`. Перед запуском служба проверяет настроенную PKI или конфигурацию двух туннелей и отклоняет совпадения имён, приводящие к случайному обновлению сертификата. Список профилей читается с диска. «Синхронизировать» перечитывает каталог.

На локальном тестовом узле с установленным AntiZapret и службой `adminpanelaz-lws.service` запустите из каталога проекта после сборки:

```sh
sudo sh deploy/install-client-helper.sh build
```

Установщик создаёт отдельную группу доступа, включает Unix-сокет и перезапускает панель с доступом к нему. Веб-процесс остаётся изолированным пользователем systemd. Один короткий запрос отправляется по сокету без запуска дочернего процесса в панели. Системная служба обрабатывает запрос от root, обращается к `/root/antizapret/client.sh` и сериализует изменения через `/run/adminpanelaz-lws-client.lock`. В группу доступа к сокету входит сервис панели. Веб-операции требуют сессию администратора и актуальный контекст локального узла.

Одновременно выполняется одна операция. При ошибке проверьте состояние в списке профилей и журналы установленных VPN-служб. Для удаления повторный вызов с отсутствующим клиентом считается завершённым. Вкладка «Клиенты» показывает результат последней операции, пока процесс панели работает.

Сценарий с синтетической PKI и конфигурацией WireGuard проверяет сокет, создание и удаление клиентов, выборку профилей по страницам и точное сопоставление файлов с именами клиентов:

```sh
python3 tests/local_vpn.py build/adminpanelaz-client build/adminpanelaz-lws
```
