# Вход через Telegram

В разделе «Настройки» → «Разделы панели» включите модуль Telegram. Затем откройте раздел «Telegram», укажите имя и токен бота, включите Telegram Login Widget и задайте время действия подписи. Telegram требует зарегистрировать домен панели в BotFather. Токен хранится в `lws-telegram.db` внутри каталога данных. API настроек возвращает только признак его наличия.

Пользователь входит в панель своим обычным способом, открывает раздел «Telegram» и подтверждает свой Telegram ID через виджет. После привязки он может выбрать «Войти через Telegram». При входе действуют IP-ограничения, ограничение попыток, CAPTCHA и второй фактор панели. Отвязка завершает остальные сеансы этой учётной записи.

## Перенос привязок

Используйте одну и ту же офлайн-копию базы оригинала для предварительного переноса аккаунтов и привязок.

```sh
adminpanelaz-migration import-legacy-accounts offline-adminpanel.db auth.db
adminpanelaz-migration import-legacy-telegram offline-adminpanel.db auth.db lws-telegram.db
```

Команда проверяет совпадение идентификаторов и имён перенесённых аккаунтов. Она переносит привязки, имя бота и время действия подписи. Повторный импорт из той же копии сохраняет сделанные после переноса изменения. Токен бота и включение входа задаются в настройках панели после установки пары файлов `auth.db` и `lws-telegram.db`.

## Проверка совместимости

Синтетические тесты проверяют подтверждение Login Widget и подпись `initData`, одноразовость авторизации, второй фактор, CAPTCHA и отзыв сеансов. Проверка с реальным ботом, OIDC, запуск Mini App с прежними URL и bearer API, выдача профилей, команды бота, уведомления и запланированные отправки входят в оставшуюся [приёмку](upstream-compatibility.md).
